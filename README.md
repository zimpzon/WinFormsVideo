## Quick start
Get started in 1 minute. Run the program. Paste in the path of a video file. Press play.

## Intendend start
The demo streams video over RTSP.
Create the folder c:\WinFormsVideo.
Place ffmpeg.exe, mediax.exe and a video named video.mp4 in the folder.
Run sender.bat.
Start the program.
Press play. The default URI connects to the stream exposed by sender.bat.
