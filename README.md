## Get started

This demo plays RTSP video streams in WinForms

If you already have an RTSP stream...
    Start the program
    Enter the RTSP address
    Press play

If you don't have an existing RTSP stream...
    Create the folder c:\WinFormsVideo
    Place ffmpeg.exe, mediax.exe and a video named video.mp4 in the folder.
    Run sender.bat
    Start the program
    Press play
